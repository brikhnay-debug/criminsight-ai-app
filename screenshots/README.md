# Screenshots

This folder is referenced by the main `README.md` and is currently a placeholder.

Once the UI is stable, add the following images here (1280×800 or similar, PNG):

- `landing.png` — the marketing landing page
- `login.png` — the login screen
- `signup.png` — the signup screen
- `dashboard.png` — the authenticated dashboard overview
- `ask-ai.png` — the Ask AI chat interface, ideally mid-conversation with a Markdown-formatted response visible

Tips for good screenshots:
- Use a real (or realistic seed) account, not empty states, so the UI looks populated.
- Capture at a standard desktop width (e.g. 1440px) for consistency.
- Consider adding a matching set of mobile screenshots (e.g. `dashboard-mobile.png`) once the responsive layouts are finalized.
